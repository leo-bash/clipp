# Media engine

`@shortfactory/storage` owns the storage contract. The local adapter copies objects below a configured root, rejects absolute or traversal keys, preserves per-object metadata, and exposes a retention cleanup hook that skips legal holds and preserved objects. `S3StorageProvider` implements the first remote path for Cloudflare R2/S3-compatible endpoints; `createConfiguredStorageProvider` selects it only when endpoint, bucket and credentials are all present.

`@shortfactory/video` keeps media work outside the API process. `FFmpegRenderer` probes the source, crops it to an even vertical canvas, applies an optional trim and ASS caption track, encodes H.264/AAC with a fast-start MP4 layout, and runs QC on the resulting file. Critical QC failures reject the render: wrong resolution, invalid duration, zero-byte output, non-H.264 video, missing required audio, an oversized file, or a video that is black for essentially its entire duration. Caption cues are validated for non-empty valid ranges and safe margins before FFmpeg is invoked.

The render worker imports the renderer and the container installs both `ffmpeg` and `ffprobe`. Subtitle presets (`clean`, `dynamic`, `minimal`) produce wrapped ASS cues within configurable safe-zone margins. The renderer also supports image overlays, optional blurred-background composition, audio volume control, metadata, compression settings and thumbnail extraction. The acceptance tests generate landscape fixtures and verify valid 1080x1920 MP4 outputs with H.264 video.
